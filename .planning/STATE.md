## Key Architectural Decisions
1. **Visual Theme**: Year 2099 Cyberpunk Luxury Arcade Terminal — deep black void with high-contrast electric emissions (Cyan, Orange, Neon Yellow, Matrix Green, Electric Blue, Ultra Violet, Magenta), smoked glass hardware buttons, and glowing plasma energy containment cylinders.
2. **Framework & Stack**: React 18, TypeScript (Strict), Vite, Zustand, Motion/CSS transforms, Web Audio API procedural synthesis.
3. **Core Rules Integrity**: Strict 100% adherence to `PRD.md` rules (capacity $C=4$, 3 tiers with 5/7/9 tubes, 2 empty tubes, 5 undos, deterministic 36 solver-verified levels).
4. **Zero-Lag Logic**: Game logic computes instantly; visual bubble flight arcs run decoupled on RAF/CSS transitions.
5. **No External Network Dependencies**: Self-contained procedural Web Audio sounds, vector SVG graphics, self-hosted fonts, and offline PWA capability.
